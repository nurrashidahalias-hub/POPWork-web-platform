# POP!Work – Web Gig Platform

POP!Work is a web-based gig job platform developed as a Final Year Project to connect students and the community with flexible job opportunities.

## Technologies
- HTML
- CSS
- PHP
- JavaScript
- MySQL
- OpenStreetMap
- Leaflet.js

## Features
- Job posting
- Job application
- GPS check-in
- Role-based system (Employer / Job Seeker / Admin)
