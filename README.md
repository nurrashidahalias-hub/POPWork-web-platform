# POP!Work – Gig Job Platform for Community

POP!Work is a web-based gig job platform designed to connect students and community members in Sabah with flexible job opportunities.

This project was developed as a Final Year Project for the Bachelor of Computer Science (Software Engineering) programme at Universiti Malaysia Sabah.

---

## Problem

Many students and community members struggle to find short-term or part-time job opportunities.

POP!Work aims to solve this by creating a centralized gig marketplace where employers can post jobs and job seekers can apply easily.

---

## Key Features

- User registration and authentication
- Job posting system for employers
- Job browsing and application for job seekers
- GPS check-in functionality for job attendance
- Role-based dashboard (Admin / Employer / Job Seeker)
